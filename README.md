## 🌷 About the Project

Hello! (´｡• ᵕ •｡`)♡

This is my first experimental game project developed using Unity. Developed in 2024.

The game is a 2D project that combines story-based gameplay with several mini-games.

I wanted to try creating a visual novel-style game with interactive elements such as:

- Geometry Dash-style obstacle mini-game  
- Maze navigation gameplay  
- Mario-style jumping mechanics  
- Fate-style random outcome mechanics  

## 🎨 Art

The main character was drawn from scratch by me using Aseprite.

The menu character was drawn using a graphics tablet in Paint Tool SAI 2.

Some game assets were obtained from free public sources.

## ✨ Personal Experience

Since this was my first experience in Unity game development, the project was created for learning and experimentation.

The main goal was to explore:

- Basic 2D game mechanics  
- Simple story structure  
- Mini-game implementation  
- Character control logic
